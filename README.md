# DEMOLITION CITY (파괴의 도시)

버려진 사막 도시를 3D로 달리며 60초 동안 건물과 구조물을 들이받아 부수는 웹 아케이드 게임입니다.

## 플레이

`index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 바로 플레이할 수 있습니다.

| 조작 | 키보드 | 휴대폰 |
| --- | --- | --- |
| 이동 / 방향 | W A S D, 방향키 | 화면 아래 ◀ ▶, 가속, 후진 |
| 브레이크 | Space | 브레이크 버튼 |
| 니트로 | Shift | 니트로 버튼 |

## 규칙

- 60초가 지나거나 차량 내구도가 0이 되면 게임오버
- 소형 구조물 100점, 대형 건물 300점 × 충돌 속도 배율 × 콤보 배율
- 대형 건물은 차량별 기준 속도 이상으로 들이받아야 쓰러지고, 쓰러진 자리의 구조물은 연쇄로 부서짐
- 목표 미션 3개(대형 5채, 콤보 ×5, 8,000점), 달성마다 +500점

## 차량

| 차량 | 최고 속도 | 내구도 | 대형 건물 파괴 속도 |
| --- | --- | --- | --- |
| COBALT 2107 (세단) | 94km/h | 100 | 51km/h 이상 |
| VIPER GT (머슬카) | 122km/h | 70 | 60km/h 이상 |
| RANCHER 4X4 (픽업트럭) | 86km/h | 145 | 39km/h 이상 |
| WRECKER 9000 (철거 트럭) | 68km/h | 220 | 28km/h 이상 |

## 기술

- three.js r128 (CDN), 이미지 파일 없이 모든 텍스처를 코드로 생성
- 물리 기반 하늘과 반사광, 블룸·색감 보정 후처리
- 휴대폰 폭 360px 대응, 그래픽 고품질 / 절전 설정

## 랭킹 안내

전체(공유) 랭킹은 claude.ai 아티팩트 안에서만 동작합니다. 이 파일을 직접 열거나 GitHub Pages에서 실행하면 랭킹은 "이 기기 기록"(브라우저에 저장되는 상위 10개)으로만 표시됩니다.
